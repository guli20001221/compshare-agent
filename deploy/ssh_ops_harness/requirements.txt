# SSH-ops harness runtime dependencies — pin here so the prod pod reproduces a validated stack in an
# isolated venv (NOT the system/anaconda Python).
#
# ⚠️ NOTHING here is checked at boot. This file used to claim a "boot preflight (P2)" that refuses to
# construct the Service unless these import cleanly; there is no such preflight. buildSSHOpsService
# validates harness_path, base_url and the resolved API key, but passes `python` through unvalidated
# (empty falls back to the system python3, which has no claude_agent_sdk). A missing or drifted dep
# therefore first appears as a FAILED USER-FACING DIAGNOSIS, after the user has already approved the
# authorization card. Verify the Python environment on the target host by hand.
#
# ⚠️ Any version change here MUST re-run `python test_guardrails.py` on the target host before the
# lane is enabled — the credential-bearing SSH transport rides paramiko, so its version is a security
# surface, not a convenience. (This file also used to name a `smoke_harness_protocol.py`; no such
# script exists. The six test_*.py suites are OFFLINE — no ModelVerse, no SSH, no network — so passing
# them says the guardrails are intact, NOT that the chain works; only a real run against a real box
# covers the chain. One exception since 2026-08-14: test_harness.py IMPORTS this SDK when it is
# installed, to build the real ClaudeAgentOptions and assert INV-9 against it. Still no network, and
# it self-skips with a printed SKIPPED line when the SDK is absent — but that is why CI installs the
# pinned version below, since a skipped invariant is not a checked one.)

# The Claude Agent SDK that drives the agentic loop. INV-9 pins its three off-switches together:
# tools=[] (NO built-in exists on the control-plane host), skills=[] (explicit empty listing — the
# SDK documents None as "CLI defaults still apply", i.e. NOT off) and setting_sources=[] (no
# CLAUDE.md / ~/.claude is loaded). `Skill` was the single permitted built-in until the last bundled
# playbook was deleted on 2026-08-14; it is now denied like every other one.
# Exact-pinned: this is the version validated on 2026-07-23 (harness smoke + 265/265 guardrails), and
# the pin is load-bearing for more than reproducibility — assert_single_tool encodes what THIS
# version does with an empty `skills` list. Its wheel bundles Claude Code 2.1.185 and prefers that
# binary by default; harness.py explicitly sets cli_path to the operator/image-installed 2.1.218,
# which is the direct-ModelVerse-tested runtime. Do not remove that override merely because importing
# this package succeeds. A bump here must be mirrored in .github/workflows/go-test.yml.
claude-agent-sdk==0.2.106

# SSH transport. The harness touches only the stable SSHClient / connect / exec_command / host-key-policy
# surface, unchanged across paramiko 2.x -> 3.x. Dev-validated against 2.8.1 (anaconda default), but
# 2.8.1 predates the CVE-2022-24302 (private-key file race) fix, so prod pins the maintained 3.x line
# rather than reproduce a vulnerable version.
# TODO(lead): after a pod smoke on the chosen 3.x patch, hard-pin the exact version here (== not range).
paramiko>=3.4,<4
